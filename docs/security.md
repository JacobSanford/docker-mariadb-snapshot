# Security Vulnerabilities

## Reporting Security Issues

**Do NOT file public GitHub issues for security vulnerabilities.**

To report a security vulnerability, please contact the project maintainers directly:

1. **Preferred**: Use [GitHub Security Advisories](https://github.com/JacobSanford/docker-mariadb-snapshot/security/advisories/new) to privately report vulnerabilities
2. **Alternative**: Contact the repository owner directly through GitHub

## What to Include

When reporting a vulnerability, please provide:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

## Response Time

We aim to respond to security reports within 72 hours and will work with you to address the issue promptly.

See [Important Considerations](important-considerations.md) for general security guidance when using this project.
